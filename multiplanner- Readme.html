MultiGraphPlanner: Planejamento Ótimo de Missões para Robôs Autônomos

1. Introdução

O MultiGraphPlanner é um planejador de missões para robôs autônomos, utilizando um modelo de grafos para representar o ambiente e otimizar a alocação de tarefas. O sistema distribui tarefas entre múltiplos robôs de forma eficiente, considerando:

  • Custos de deslocamento entre nós do ambiente.

  • Tempos de execução das missões.

  • Restrições de execução (quais robôs podem executar quais missões).

  • Dependências entre missões.

  • Minimização do tempo total de execução.

O planejador gera um cronograma otimizado e um gráfico de Gantt, facilitando a visualização das tarefas e sua execução em tempo mínimo.

2. Tecnologias Utilizadas

  • NetworkX: Modelagem do ambiente e das missões como grafos.

  • A*: Algoritmo de busca heurística para encontrar caminhos ótimos.

  • Permutações: Busca combinatória para alocar as missões de forma ótima.

  • Ordenação Topológica: Respeito às dependências entre missões.

  • Matplotlib: Visualização do cronograma de execução por meio de gráficos de Gantt.

3. Estrutura do Código

O código é implementado na classe MultiGraphPlanner, que contém os métodos responsáveis pelo planejamento e execução das missões.

3.1 Estrutura de Dados

O código trabalha com um grafo estruturado a partir da conversão feita pelo método:

grafo_mapa = AABBUtils.convert_graph_to_dict(G_p)

Este grafo é armazenado como um dicionário contendo:

  • ``: Conjunto de nós representando posições do ambiente.

  • ``: Dicionário contendo as conexões entre os nós e seus pesos (tempo de deslocamento).

Outras estruturas incluem:

  • ``: Dicionário associando missões a nós do grafo.

  • ``: Dicionário contendo tempos de execução de cada missão.

  • ``: Dicionário definindo quais robôs podem executar cada missão.

5. Como Executar

5.1 Dependências

Certifique-se de ter instalado as seguintes bibliotecas:

pip install networkx matplotlib

5.2 Executando o Código

from multigraphplanner import MultiGraphPlanner
from aabbutils import AABBUtils

grafo_mapa = AABBUtils.convert_graph_to_dict(G_p)
planner = MultiGraphPlanner(grafo_mapa, G_m, G_r, mission_positions, mission_times, mission_execution)
optimal_plan, min_time, schedule = planner.find_minimum_mission_time_plan(robots_positions)
planner.execute_plan(optimal_plan, min_time, schedule)
